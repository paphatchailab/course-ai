ผู้เข้าอบรม: Developers | รูปแบบ: ทฤษฎี + Workshop + Demo + นำเสนอ

ตารางเวลาและเนื้อหา

ช่วงเช้า (ทฤษฎี + Demo)

  • แนะนำตัวผู้สอน, ภาพรวม Agenda, และเป้าหมายการเรียนรู้
  • สอบถามความคาดหวัง และ ประสบการณ์เกี่ยวกับ Workflow Automation

สิ่งที่จะได้รับ: เข้าใจภาพรวมและเป้าหมายของหลักสูตร

  • LangChain คืออะไร? บทบาทในการสร้าง AI Application
  • RAG (Retrieval-Augmented Generation) คืออะไร? แก้ปัญหา Hallucination อย่างไร?
  • Vector Database & FAISS: แนวคิดการจัดเก็บและค้นหาข้อมูล Vector
  • การประมวลผล PDF เบื้องต้นสำหรับการทำ RAG (Chunking)
  • ภาพรวมการทำ RAG แบบง่ายๆผ่าน LangChain

สิ่งที่จะได้รับ: เข้าใจแนวคิด RAG, รู้จักเครื่องมือ LangChain, FAISS และความสำคัญของการประมวลผลเอกสารเบื้องต้น

  • n8n คืออะไร? Use Cases (เน้น Dev)
  • Interface Overview (Editor, Nodes, Credentials, Executions)
  • Core Concepts: Workflows, Nodes, Connections
  • Data Flow & Expressions: การไหลของข้อมูล, JSON Structure, การใช้ `$json`, `$item` (สำคัญ!)
  • Demo: Workflow ง่ายๆ (Manual -> Set -> Log)

สิ่งที่จะได้รับ: รู้จัก n8n, เข้าใจส่วนประกอบพื้นฐาน, และวิธีการที่ข้อมูลไหลผ่าน Workflow รวมถึงการเข้าถึงข้อมูลเบื้องต้น

พักเข้าห้องน้ำ/ดื่มน้ำ กินขนม ฯลฯ

สิ่งที่จะได้รับ: ความสดชื่น!

  • Triggers: Manual, Schedule, Webhook, Chat
  • AI Agent Nodes: อธิบาย Model, Memory, Tools, System Prompt
  • Common Nodes: HTTP Request, Set, IF, Switch, Function/Function Item, Merge
  • Execution Log & Debugging: วิธีดู Log, ดู Error
  • Demo: API Interaction Workflow (ประยุกต์ใช้งาน API ร่วมกับ AI Agent)
  • Q&A ช่วงเช้า

สิ่งที่จะได้รับ: รู้จักและเข้าใจวิธีใช้ Node ที่สำคัญ, การตั้งเวลาและรับข้อมูลจากภายนอก, การจัดการข้อมูลและเงื่อนไข, การเขียนโค้ด JS ใน n8n, และเทคนิคการ Debug

พักรับประทานอาหารกลางวัน

สิ่งที่จะได้รับ: พลังงานสำหรับช่วงบ่าย!

ช่วงบ่าย (Demo + Workshop + Presentation)

  • RAG คืออะไร? แก้ปัญหาอะไร?
  • Vector Database คืออะไร? (ตัวอย่าง Pinecone)
  • n8n Orchestrate RAG ได้อย่างไร (Mapping Steps to Nodes)
  • Live Demo: สาธิต Workflow RAG ที่เตรียมไว้ (สร้างเว็บแชท Q&A จากเอกสาร)
  • ชี้ให้เห็นการทำงาน: Input -> Embedding -> Vector Search -> Prompt Augmentation -> LLM Call -> Output
  • Use Cases & Discussion

สิ่งที่จะได้รับ: เห็นภาพรวมและความเป็นไปได้ในการใช้ n8n กับ AI ขั้นสูง (RAG), เข้าใจขั้นตอนการทำงานของ RAG และบทบาทของ n8n ในการควบคุม

  • อธิบายโจทย์ Workshop
  • แนะนำเครื่องมือ/แหล่งข้อมูลที่จำเป็นสำหรับ Workshop

สิ่งที่จะได้รับ: เข้าใจโจทย์ Workshop, รู้จักประยุกต์ใช้ Node ต่างๆในการทำงานตาม Logic ที่ต้องการ, และทราบทรัพยากรที่ต้องใช้

  • แต่ละคนลงมือทำ Workshop ตามโจทย์ที่ได้รับ
  • ผู้สอนให้คำแนะนำ, ตอบคำถาม, และช่วยแก้ปัญหา (Troubleshooting)

สิ่งที่จะได้รับ: ประสบการณ์ลงมือสร้าง Workflow จริง, การประยุกต์ใช้ความรู้จากช่วงเช้า, ฝึกการแก้ปัญหาเฉพาะหน้า

พักผ่อนสั้นๆ และเตรียมตัวนำเสนอ Workshop

สิ่งที่จะได้รับ: เตรียมความพร้อมสำหรับการนำเสนอ

  • แต่ละคนนำเสนอผลงาน Workshop (ประมาณ 5-7 นาที/คน)
  • เนื้อหา: โจทย์, Workflow, เทคนิคที่ใช้, ปัญหาและการแก้ไข
  • เปิดให้มีการถามคำถาม/ให้ Feedback

สิ่งที่จะได้รับ: เรียนรู้จาก Use Case ของคนอื่น, ฝึกทักษะการนำเสนอ, ได้รับ Feedback เพื่อปรับปรุง

  • ตอบคำถามเพิ่มเติม
  • สรุปภาพรวมสิ่งที่ได้เรียนรู้ในวันนี้
  • แนะนำแหล่งข้อมูลเพิ่มเติม (Docs, Forum)
  • ปิดการอบรม

สิ่งที่จะได้รับ: เคลียร์ข้อสงสัย, ทบทวนความรู้, รู้แหล่งศึกษาต่อยอด
